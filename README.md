# 기울어진 마을을 구하라! : AI 개발자 미션

> 누구의 가능성도 놓치지 않는 AI 개발자가 되어 보세요.

초등학교 5~6학년 인공지능 윤리 수업(약 10분)을 위한 **데이터 편향성 체험 웹앱**입니다.
학습 데이터의 편향을 직접 찾아 고치며, 공정하고 포용적인 인공지능을 만드는 개발자의 책임을 체험합니다.

## 활동 흐름

| 단계 | 시간 | 학생 활동 |
|---|---|---|
| 1. 결과 확인 | 1분 | 관심과 적성이 같은 민준·민서가 다른 직업을 추천받는 것을 발견 |
| 2. 데이터 탐색 | 2분 | AI가 배운 데이터에서 편향(여성 개발자 사례 부족) 찾기 |
| 3. 개선 | 3분 | 실험 1: 같은 데이터를 늘려도 결과가 그대로 / 실험 2: 빠진 사례를 모아 민서의 추천 바꾸기 |
| 4. 재검증 | 3분 | 공정성 표의 모든 줄을 ✓로 맞추고, 데이터에 없는 새 친구 하은이에게도 확인 |
| 정리 | 1분 | 개발자의 윤리 거울 세 질문으로 마무리 |

## 특징

- **실제로 계산하는 AI**: 결과가 미리 정해져 있지 않습니다. AI는 과거 데이터에서 관심 유형과 성별이 같은 사람들을 모아 가장 많은 직업을 추천하고, 학생이 조정한 데이터로 바로 다시 계산합니다.
- **마을 수평계**: AI가 불공정할수록 마을이 기울어지고(8°), 공정해질수록 평평해집니다(0°).
- **데이터 수집 기회 80회**: 한정된 기회 안에서 누구의 데이터가 꼭 필요한지 고민하며 조정합니다.
- **공정성 표**: 관심이 같은 남학생·여학생이 같은 추천을 받는지 한눈에 확인합니다.
- **교사용 안내**: 의도 · 흐름 · 원리 · 오개념 · 핵심 발문을 메뉴로 제공합니다.

## 이 활동이 다루는 오개념

- 데이터가 많으면 편향이 사라진다?
- 50:50이면 공정하다?
- 데이터만 고치면 완벽하다?
- AI가 일부러 차별한다?

## 실행 방법

설치가 필요 없습니다. 폴더 전체를 내려받아 `index.html`을 웹 브라우저로 열면 됩니다.
(`index.html`만 따로 옮기면 디자인과 버튼이 동작하지 않으니 **폴더째** 사용하세요.)

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조, 마을 그림, 교사용 안내 |
| `style.css` | 디자인 (밝은 화면·어두운 화면 모두 지원) |
| `model.js` | AI 추천 원리와 데이터 숫자 |
| `art.js` | 학생 얼굴, 직업 아이콘, 축하 효과 |
| `app.js` | 화면 흐름과 상호작용 |

수업에 맞게 숫자를 바꾸려면 `model.js`의 `BASE`(과거 데이터), `SLIDERS`(모을 수 있는 사례), `CHANCES`(수집 기회)만 고치면 됩니다.

## 개인정보

학생의 이름이나 개인정보를 입력받거나 저장하지 않습니다. 외부로 전송하는 데이터도 없습니다.
